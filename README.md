# Ram Mandir Wedding Invitation

A responsive, animated wedding invitation sample inspired by Ram Mandir aesthetics. This repository is intended as a portfolio demo for prospective clients.

## Preview locally

Requires Node.js. No package installation is needed.

```bash
node server.js
```

Open [http://localhost:4000](http://localhost:4000) in a browser.

## Customization

Client-specific text and page structure are in `index.html`. Images are stored in `assets/`, and music is stored in `audio/`.

## Privacy

The current demo contains real names, photographs, venue information, and contact details. Replace or anonymize personal information before publishing this repository publicly.
